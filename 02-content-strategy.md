# SEO Content Strategy

Scope: realistic plan for a new GitHub Pages portfolio. Keyword volumes are **unknown** (no keyword tool), so priorities are based on relevance, buyer wording seen in search results, and expected competition. Use the free tools listed at the end to check demand before writing each article.

## Principles
- Create a page only when it answers something real. No duplicate "country" pages, no thin pages.
- Only write what you can truthfully say. Don't invent clients, results, or certifications.
- One main keyword per page; write for the reader first.

## Phase 1 — Strengthen the homepage (no new pages)
- Title/description should include "Email Marketing Expert", "Email Marketing Services" and "Shopify / Klaviyo".
- Add a short plain-text "Services" intro that uses the words buyers search ("email marketing services for small businesses", "Klaviyo email flows for Shopify").
- Add an H3 under each service card; keep one H1.

## Rules for these pages
- Add each URL to sitemap.xml and link it from the homepage.
- Each page: unique title, description, one H1, canonical, BreadcrumbList schema (optional), clear contact CTA.
- Don't use screenshots or numbers that are not yours.

## Free tools to check demand yourself
Google Trends, Google autocomplete / "People also ask", Bing Webmaster Tools (free), Ubersuggest/Keyword Surfer (limited free), AnswerThePublic (limited free).
